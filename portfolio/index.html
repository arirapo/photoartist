Notes

Working principles

This is not meant to be a complete archive. It is a selected and evolving field of entry points.

The portfolio may include photographic series, long-form projects, conceptual web pieces, QR-linked works, and token-based extensions.

The current version is intentionally sparse. It serves as a durable base for future additions.

Titles, section labels and emphasis can be refined later without altering the basic structure.
