PORTFOLIO STARTER

This is a static modular portfolio framework.

MAIN IDEA
- Keep the portfolio separate from the main artist site.
- Build it slowly, one project at a time.
- Each project can live in its own folder.

BASIC STRUCTURE
portfolio/
  index.html
  styles.css
  script.js
  projects/
    project-template/

HOW TO START A NEW PROJECT
1. Duplicate the folder:
   projects/project-template/

2. Rename it, for example:
   projects/traces-between/
   or
   projects/cameo/

3. Edit:
   - index.html
   - project.css
   - project.js
   - data.json

4. Add a new card to portfolio/index.html linking to the new project.

NOTES
- Everything is static and portable.
- No database is required.
- The template project reads its content from data.json.
- You can later remove JSON and hardcode the project page if you prefer.
